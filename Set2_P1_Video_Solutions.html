Question 1

Validation, verification and check digits (CrowdTaskSG) · 13 marks

CrowdTaskSG is a government platform on which members of the public take part in paid surveys, quests and A/B testing that help government agencies improve their services. It is open to Singapore citizens and permanent residents aged 15 and above who have a Singpass account.

In a proposed design, each participant is given a 7-character participant ID made up of the letter C, five digits and a check letter, for example C40213J. The check letter is calculated as follows:

  1. Multiply the five digits by the weights 6, 5, 4, 3 and 2 respectively.
  2. Add the five products to give Total.
  3. Calculate R ← Total MOD 11.
  4. The check letter is the character at position R of the string "ABCDEFGHJKL", where the first character is at position 0.

For example, for C40213: 4×6 + 0×5 + 2×4 + 1×3 + 3×2 = 41, 41 MOD 11 = 8, so the check letter is "J".

1(a) [2 marks]

Explain the difference between data validation and data verification. Give an example of each that could be used when a participant registers on CrowdTaskSG.

Suggested solution

Validation is an automatic check by the program that data is sensible and follows set rules; it cannot tell whether the data is actually correct. Example: a range check that the age is 15 or above, or a format check on the participant ID. [1]

Verification checks that the data entered matches the original source or what the user intended. Example: asking the participant to enter the email address twice, or retrieving name and date of birth from Singpass for the participant to confirm. [1]

Both definitions needed, each with a suitable example.

1(b) [3 marks]

Calculate the check letter for the participant ID that begins C57381. Show your working.

Suggested solution

Position 4 of "ABCDEFGHJKL" is "E", so the ID is C57381E [1]

1(c) [2 marks]

A participant with the ID C57381 followed by the correct check letter types C75381 followed by the same check letter. Explain how the check letter allows this error to be detected.

Suggested solution

The digits 5 and 7 are multiplied by different weights, so swapping them changes the weighted total: 7×6 + 5×5 + 3×4 + 8×3 + 1×2 = 105, 105 MOD 11 = 6, giving check letter "G". [1]

The recalculated check letter "G" does not match the "E" that was typed, so the ID is rejected and the transposition error is detected. [1]

1(d) [5 marks]

Write pseudo-code for the function IsValidID(ID : STRING) RETURNS BOOLEAN that returns TRUE only if:

  • ID is exactly 7 characters long
  • the first character is "C"
  • the characters at positions 1 to 5 are all digits
  • the last character is the correct check letter.

Positions start at 0. You may use ID[i] to return the character at position i, and ASC(ch), which returns the ASCII code of ch. The ASCII codes for "0" to "9" are 48 to 57.

Suggested solution
FUNCTION IsValidID(ID : STRING) RETURNS BOOLEAN
   DECLARE Letters : STRING
   DECLARE Total, i, Code : INTEGER
   Letters ← "ABCDEFGHJKL"
   IF LENGTH(ID) <> 7 THEN
      RETURN FALSE
   ENDIF
   IF ID[0] <> "C" THEN
      RETURN FALSE
   ENDIF
   Total ← 0
   FOR i ← 1 TO 5
      Code ← ASC(ID[i])
      IF Code < 48 OR Code > 57 THEN
         RETURN FALSE                // not a digit
      ENDIF
      Total ← Total + (Code - 48) * (7 - i)   // weights 6, 5, 4, 3, 2
   NEXT i
   IF ID[6] = Letters[Total MOD 11] THEN
      RETURN TRUE
   ELSE
      RETURN FALSE
   ENDIF
ENDFUNCTION

1 mark: length check (7 characters) and first character "C"
1 mark: loop over positions 1 to 5, rejecting any character whose ASCII code is outside 48 to 57
1 mark: converts each digit to its value (ASC(ch) − 48)
1 mark: multiplies by the correct weight (6, 5, 4, 3, 2) and accumulates the total
1 mark: compares ID[6] with the letter at position Total MOD 11 and returns the correct Boolean

Checked by running an equivalent program: C40213J and C57381E valid; C75381E, C5738XE, C57381 and D40213J invalid.

2(c) [2 marks]

When a user pans the map slightly, one new distance is added to the end of a list of 2000 distances that is already in ascending order, and the list must be sorted again. Explain why an insertion sort is more suitable than this quicksort for this task.

Suggested solution

The list is already sorted except for the new item. Insertion sort only has to shift the new item back into position, so it makes very few comparisons (close to its best case of O(n)). [1]

Quicksort with the first element as pivot performs very badly on sorted or nearly sorted data: each partition removes only one element, giving its worst case of O(n²) and deep recursion. [1]

Question 4

Public key cryptography and authentication (Singpass passkey) · 10 marks

GovTech encourages Singpass users to create a passkey. Information shown to the public includes the following:

  • Passkeys are a safer way to log in and offer stronger protection against phishing scams.
  • Passkeys only work on the legitimate Singpass login domain and cannot be used on fake websites.
  • Users authenticate using their biometrics or 6-digit Singpass app passcode during passkey logins.
  • Passkeys are stored securely on the device.
  • No passwords or OTPs are entered during passkey logins, so there is nothing for scammers to steal.

A passkey uses asymmetric (public key) cryptography. When a user creates a passkey, the user’s phone generates a key pair. The private key is kept on the phone and the public key is sent to the Singpass server, which stores it with the user’s account.

4(a) [2 marks]

Explain why it is safe for the Singpass server to store the public key, but the private key must never leave the phone.

Suggested solution

The public key can only be used to check (verify) signatures, not to create them, and the private key cannot be worked out from it, so a stolen copy of the server’s stored public keys does not let anyone log in. [1]

Anyone who has the private key can create valid signatures and log in as the user, so it must stay on the phone (in secure storage) and never be sent over the network. [1]

Video walkthrough (1:01)

4(b) [3 marks]

At each login, the Singpass server sends a new random value, called a challenge, to the phone. Describe how the challenge and the stored public key are used to authenticate the user.

Suggested solution

The phone signs (encrypts) the challenge, or a hash of it, with the user’s private key, after the user unlocks the passkey, and sends the signature back to the server. [1]

The server uses the public key stored with the user’s account to verify (decrypt) the signature and checks that it matches the challenge it sent. [1]

If they match, only the holder of the private key could have produced the signature, so the user is authenticated. Because the challenge is new and random each time, a signature captured earlier cannot be replayed. [1]

Video walkthrough (1:13)

4(c) [3 marks]

Explain why a passkey gives better protection against a phishing website than logging in with a password and a one-time password (OTP).

Suggested solution

With a password and OTP, the user types secrets that a fake website can capture and immediately use (relay) on the real Singpass site. [1]

With a passkey, nothing secret is typed or sent: the private key never leaves the phone, and the signature only answers one challenge. [1]

The passkey is tied to the legitimate Singpass domain, so the phone will not use it on a fake website with a different domain, so the phishing site gets nothing it can reuse. [1]

Video walkthrough (1:02)

4(d) [2 marks]

Explain why a passkey login, in which the user unlocks the passkey with a fingerprint or the Singpass app passcode, is a form of multi-factor authentication.

Suggested solution

It combines two different types of factor: something the user has (the phone holding the private key) [1]

and something the user is (fingerprint or face) or knows (the 6-digit passcode), needed to unlock the passkey. [1]

Recursion and 2D arrays (OneMap barrier-free routing) · 12 marks

OneMap offers Barrier-Free Access Routing for persons with disabilities, wheelchair users, seniors and families with prams. A student models a small area as a two-dimensional array Map of BOOLEAN values. Map[r][c] is TRUE if the square in row r and column c can be used by a wheelchair, and FALSE if it cannot (for example, it has steps).

A wheelchair user starts at Map[0][0] and can only move one square South (to row r + 1) or one square East (to column c + 1) at a time. The recursive function Routes returns the number of different routes from Map[0][0] to Map[r][c].

01   FUNCTION Routes(Map, r : INTEGER, c : INTEGER) RETURNS INTEGER
02      DECLARE Total : INTEGER
03      IF Map[r][c] = FALSE THEN
04         RETURN 0
05      ENDIF
06      IF r = 0 AND c = 0 THEN
07         RETURN 1
08      ENDIF
09      Total ← 0
10      IF r > 0 THEN
11         Total ← Total + Routes(Map, r - 1, c)
12      ENDIF
13      IF c > 0 THEN
14         Total ← Total + Routes(Map, r, c - 1)
15      ENDIF
16      RETURN Total
17   ENDFUNCTION

5(e) [4 marks]

Write pseudo-code for an iterative function RoutesIter(Map, R, C) that returns the same value as Routes(Map, R, C). Your function should use a two-dimensional array Count to store the number of routes to each square.

Suggested solution
FUNCTION RoutesIter(Map, R : INTEGER, C : INTEGER) RETURNS INTEGER
   DECLARE Count : ARRAY[0:R, 0:C] OF INTEGER
   FOR i ← 0 TO R
      FOR j ← 0 TO C
         IF Map[i][j] = FALSE THEN
            Count[i][j] ← 0
         ELSE
            IF i = 0 AND j = 0 THEN
               Count[i][j] ← 1
            ELSE
               Count[i][j] ← 0
               IF i > 0 THEN
                  Count[i][j] ← Count[i][j] + Count[i - 1][j]
               ENDIF
               IF j > 0 THEN
                  Count[i][j] ← Count[i][j] + Count[i][j - 1]
               ENDIF
            ENDIF
         ENDIF
      NEXT j
   NEXT i
   RETURN Count[R][C]
ENDFUNCTION

1 mark: nested loops over rows 0 to R and columns 0 to C, in an order that fills squares north and west before they are needed
1 mark: Count[i][j] ← 0 for an unusable square and Count[0][0] ← 1
1 mark: Count[i][j] = Count[i − 1][j] + Count[i][j − 1], with checks for i > 0 and j > 0
1 mark: returns Count[R][C]

Checked by running an equivalent program: returns 3 for MapA (1, 2) and 3 for MapB (2, 3).

7(e) [3 marks]

During the festival, a server that hosts an online registration page receives a very large number of requests from thousands of computers that have been infected with malware.

Explain how this attack can make the registration page unavailable, why a firewall that filters traffic may not be able to stop it, and how an intrusion prevention system (IPS) could help.

Suggested solution

This is a distributed denial of service (DDoS) attack: the infected computers send so many requests that the server’s processing power, memory or network bandwidth is used up, so genuine users’ requests are delayed or not answered. [1]

A firewall filters traffic using rules such as allowed IP addresses and ports; the attack traffic comes from thousands of different addresses and looks like normal web requests to an allowed port, so the rules cannot easily tell it apart from genuine traffic. [1]

An IPS monitors traffic for suspicious patterns (for example, an abnormal rate of requests) and automatically blocks or drops the attacking traffic before it reaches the server. [1]

Question 8

Generative AI, software clones and ethics · 15 marks

In October 2026, news media reported that a small developer had used a generative AI model, directing eight AI coding agents working in parallel, to produce a suite of free, open-source applications that closely imitate the look and main features of Adobe’s Creative Cloud applications, such as Photoshop and Lightroom. The developer of a similar Photoshop-style editor said that it cost about US$2,000 in AI usage to build. Commentators asked whether this was a “SaaSpocalypse 2.0”, in which AI makes subscription software (Software as a Service) cheap to copy.

The applications are downloaded and installed from a code-sharing website. One of the applications was reported to have more than 1,700 automated tests, and 307 of 309 test image files were opened and saved again without any change.

8(a) [3 marks]

Explain one risk to a user who downloads such an application from an unofficial source, and explain how a digital signature on the download could reduce this risk.

Suggested solution

Risk: the download may be a fake or altered copy containing malware (for example, a trojan or ransomware) that could steal data or damage files. [1]

The developer signs the file with their private key (a signed hash of the file); the user’s computer uses the developer’s public key, from a trusted digital certificate, to check the signature against a fresh hash of the downloaded file. [1]

If the check succeeds, the file really came from that developer and has not been altered since it was signed; an altered or fake file is detected and can be rejected. [1]

A signature shows who published the file and that it is unchanged. It does not prove the software is free of bugs or harmful behaviour.

8(b) [3 marks]

Eight AI agents made changes to the same program code at the same time. Explain why version control and naming conventions are needed in this situation.

Suggested solution

Any three, 1 mark each:

  • version control keeps a record of every change, with who (which agent) made it and when, so a faulty change can be traced
  • earlier working versions can be restored (rolled back) if a change breaks the program
  • changes made at the same time to the same file can be detected and merged, so one agent does not overwrite another’s work
  • naming conventions (for files, branches, versions, identifiers) make it clear which version is the latest and keep the code consistent and easy to understand for humans and agents

8(d) [6 marks]

Discuss the social, ethical, legal and economic issues that arise when generative AI can be used to produce working copies of commercial software cheaply.

Suggested solution

Mark by levels. Indicative content (credit other relevant points):

Social

  • free tools widen access for students and small creators who cannot afford subscriptions
  • jobs and skills of software developers change: fewer people are needed to write code, while skills in testing, reviewing and specifying grow

Ethical

  • is it fair to copy the look and features of a product that another company spent years and large sums developing?
  • responsibility for AI-generated code: a computing professional who publishes it should test it, avoid harm to users, be honest about its limits (early version, incomplete features) and respect intellectual property, as in a code of conduct
  • quality and security risk: users may trust AI-built software that has not been properly checked

Legal

  • copyright and intellectual property: copying the source code, logos or icons of a product would be infringement, while re-creating features independently may be legal, but the boundary is unclear when an AI may have learned from copyrighted material
  • trademarks: names or designs that are too similar may mislead users; open-source licences decide how the clones themselves may be reused

Economic

  • lower cost of building software reduces the advantage of established subscription (SaaS) companies, which may lose customers and revenue and need to cut prices or add value (cloud sync, support, file compatibility)
  • more competition and new start-ups; investors may fear lower future profits for software companies

Levels
5 to 6 marks: a balanced discussion covering at least three of social, ethical, legal and economic issues, each explained in this context, with a reasoned conclusion
3 to 4 marks: several relevant issues explained, but limited balance or some areas missing
1 to 2 marks: issues listed with little explanation or not linked to the context
